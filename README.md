# 1% AURA ROUTINE

> 1日3人の人生を1%良くする — 人格育成ルーティンアプリ

## 起動方法

```bash
cd aura-routine
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## 使い方

### ナビゲーション（画面下部）

| タブ | 内容 |
|------|------|
| **Home** | 今日の達成率・在り方・進捗カード |
| **Routine** | 朝 / 昼 / 価値提供 / 夜の振り返り |
| **World** | 要約（アニメ・映画など） / 話術練習 |
| **Invest** | 90分タイマー・自己投資 / ToDoリスト |
| **Log** | カレンダー記録 / 週1・月1チャレンジ |

### 毎日の流れ

1. **朝** → Routine > 朝：今日の在り方・言葉テーマを決め、美容チェック
2. **昼〜夕** → Routine > 昼：人間関係チェック＆気づきメモ
3. **昼〜夕** → Routine > 価値：3人への価値提供を記録
4. **いつでも** → World > 要約：見たアニメ・映画・YouTubeを要約
5. **いつでも** → Invest > 90分：タイマーで自己投資（TOEIC等）
6. **夜** → Routine > 夜：一日を振り返り、日記を書く
7. **週1・月1** → Log > チャレンジ：背伸びの経験を記録

## データ保存について

すべてのデータは **localStorage** に保存されます。

| キー | 内容 |
|------|------|
| `dailyRecords` | 日ごとの朝・昼・夜・自己投資の記録 |
| `todos` | ToDoリスト |
| `summaries` | 要約記録（アニメ・映画等） |
| `funnyStories` | 話術練習の記録 |
| `weeklyChallenges` | 週1チャレンジ記録 |
| `monthlyChallenges` | 月1チャレンジ記録 |

- ブラウザのlocalStorageに保存されるため、**同じブラウザで再読み込みしてもデータは残ります**
- ブラウザのキャッシュクリア・プライベートモードではデータが消えます
- 初回起動時にサンプルデータが入ります（削除可能）

## 技術スタック

- React 18 + Vite
- localStorage（バックエンド不要）
- canvas-confetti（達成時の演出）
- Noto Sans JP（Google Fonts）
